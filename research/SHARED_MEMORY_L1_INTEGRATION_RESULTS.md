# BioCircuit and FlyWire shared L1 source: implemented and checked

**Executed:** October 8, 2026. **Status:** the BioCircuit BC01 consumer of the canonical Pretorius L1 artifact is functional and CI green. This does not constitute a shared synaptic, semantic, or model-state encoding.

The single authoritative source remains [Pretorius-Connectome](https://github.com/Azimn/Pretorius-Connectome), with source Git blob `718dcc2d5ba4feccdef1690d447edfcebaa9bfb5`, 450 reconstructed first-person events and 27 episodes. Source repository [L1 manifest](https://github.com/Azimn/Pretorius-Connectome/blob/main/artifacts/shared_memory/v1/manifest.json) and [compressed records](https://github.com/Azimn/Pretorius-Connectome/blob/main/artifacts/shared_memory/v1/pretorius_l1_v1.jsonl.gz) were generated once using the canonical exporter, then Git committed. BioCircuit pins both artifact Git blobs and SHA-256 payload digests, verifies IDs and chronological order, and fails closed on modified files.

[Executed BioCircuit parity workflow](https://github.com/Azimn/Pretorius-Neural-Network/actions/runs/37839516626): successful. All 16 tests passed, including original-versus-shared L1 source equality, the identical original sensory vector representation on sampled events, positive mutation tests, and the complete original and L1 BC01 demos. Both demos used the same full 450-event data, 256 neurons, seed 1842, eight exposures per memory and unchanged source language cues. Their evaluation arrays matched exactly. No new cognitive benefit is inferred from this numerical parity.

The normal `load_corpus` and BC01 architecture are unchanged. [Adapter](../biocircuit/shared_memory_adapter.py) provides `load_shared_corpus(...)` and the [BC01 CLI](../scripts/demo_biocircuit_bc01.py) accepts `--shared-l1` and `--shared-manifest`, leaving existing CLI usage intact. CI pins the source repository checkout and checks artifact presence before running new verification.

The current reused layer is **L1 structured source data only**. BioCircuit still calculates its own signed hashed lexical 256-dimensional sensory input. FlyWire still calculates its own train-fit word/bigram TF-IDF and topology projection. These are not the same feature spaces; recurrent weights and biological synaptic counts remain project-specific. [The canonical verified report](https://github.com/Azimn/Pretorius-Connectome/blob/main/results/shared_memory/L1_INTERFACE_RESULTS.md) records the exact hashes and reproduction commands.

The next uncompleted shared-interface task is a split-versioned L2 representation where, and only where, both consumers intentionally select the *same* encoder. Performance and memory measurements should be recorded separately rather than assumed from correct loading. Neither original benchmark nor any downstream Pretorius production identity state has been changed by this integration.
