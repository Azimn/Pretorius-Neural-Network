# BC01-D6A protocol — transductive action-label holdout, NOT the independent D6 acceptance test

**Frozen while CI is running, before inspecting D6A full-corpus results.** This is a first engineering diagnostic for the striking D5B result that a separately trained supervised motor decoder scored 100% on 16 **previously seen** development source decisions. It does not complete [D6 Issue #38](https://github.com/Azimn/Pretorius-Neural-Network/issues/38), which requires **independently reviewed and sealed new source event challenges plus source/episode-disjoint encoding and training**.

## Source and evaluation integrity

- Reuse exactly the original, unchanged, 450 **reconstructed** first-person events, source blob `718dcc2d5ba4feccdef1690d447edfcebaa9bfb5`, source-owner L2 v2 provider checkout `7cd631f3b533203e39465ec31c4ee42945610e2f`, 256-unit recurrent network and four originally **provisional** human-interpreted source action labels. No new autobiographical records, source labels, semantic embeddings, original experiments or The Doctor Lives edits.
- Partition the existing 16 development cards into **4 stratified folds**, each with exactly 12 action-labelled training cards (3 from each of four classes) and four held-out action-labelled evaluation cards (one per class), covering each card exactly once. No held-out card ID, action label or training cue is available in the supervised training loop.
- Evaluate both (a) the *existing* source-related heldout `probe`, and (b) 16 **new assistant-authored candidate paraphrases**, frozen as `resources/biocircuit/bc01_d6a_paraphrase_candidates_v1.json` before the results. These paraphrases are **not independently reviewed**, and may not be semantically equivalent or sufficient to disambiguate a decision. Record differences rather than relying on disputed paraphrase accuracy as conclusive. Four modern-topic unknown controls probe overconfident predictions; they have no ground-truth four-action label.
- **Important declared exposure boundary:** the original 450-record unlabeled neural background curriculum **still includes the heldout events**. The original source-owner L2 v2 feature fit is episode-disjoint *within its own seed partition*, **not refitted to remove D6A's card-heldout episodes**. And many training-card and heldout-card events share the same source episode. D6A therefore tests **held-out supervised action labels only**, not inductive unknown source memories, episode-disjoint independent learning, sealed semantic generalization or external reviewer agreement. Every trial explicitly marks `never_independent_or_sealed=true` and `source_background_contains_all_heldout_events=true`.

## Fixed 9×4 neural comparisons

- Seeds **31/37/43**, model modes **local/global/generic**, four folds each, sensory input gain fixed to the already studied high-gain **12×**. Original 450-memory × 8-tick neural background; 256 neurons, three supervised output-decoder training epochs on only the 12 fold-train cards (32 presentation ticks); neural probe settles 32 ticks. Each evaluated event is unseen *by the supervised output decoder*, but not necessarily by the recurrent substrate or lexical TF-IDF fitter.
- Compare **decoder-only with recurrent W frozen**, **decoder trained with permuted incorrect labels** (one-to-one derangement of action classes), **identical decoder frozen plus D5B cue-minus-blank recurrent W learning from the same 12 training cards**, **the same combined model with exactly its card-learned recurrent W changes lesioned back to the original background W**, **fixed untrained action-population readout**, and **lexical nearest training-card retrieval** that abstains when no informative lexical match exists.
- Additionally report a **decoder confidence-threshold abstention** rule using the bottom 10th percentile of decoder confidence estimated from the *training card cues only*. This is a weak train-calibrated heuristic, **not a statistically calibrated OOD uncertainty estimator**. On four unseen-topic unknown controls per fold, report model decisions/confidence, train-only threshold and lexical abstention; do not count unknown controls as four-action true/false decisions.
- Verify that motor-only training and wrong-label motor training **never modify recurrent W**, that all compared recurrent/lesioned models share **exactly the same frozen output-decoder weights and biases**, that heldout action labels are never fed through any neural input/efference-copy channel, and that save/reload reproduces decoder scores exactly. Keep confusion counts, macro-F1, coverage/abstention and per-case scores, separate the original and paraphrase probes, and mark the result as transductive.
- Validate D6A candidate text and source ID/label leakage before performing any evaluation, and preserve exact source/candidate/card SHA256. Run twice in independent Python processes under two `PYTHONHASHSEED` values. All numerical scores, source memberships, decisions, fold indices and controls must match exactly except measured elapsed seconds. Permanently commit the raw complete report into the feature branch, not only the expiring GitHub Actions artifact.

## Scientific decision gate

A drop from 100% earlier in-sample supervised decoder accuracy to low **fold-heldout** accuracy would directly disprove overconfident claims of even card-label transfer. Strong in-fold results are **still exploratory/transductive** and require D6B independently adjudicated held-out **source events and episodes** with the TF-IDF fitter and 450-event background excluding those events; source and query paraphrase validity must be reviewed before scores are examined.

Any claim of useful autobiographical recurrent learning requires a **specific, cross-seed gain by learned recurrent W beyond the fixed decoder with matched W-only lesion** on unseen labels and eventually independently reviewed events. A decoder-only win, semantically ambiguous paraphrases or increased source-overlap retrieval are **not** evidence of recurrent storage or a definitive Pretorius. Until the causal gate passes, do not move neural weights to The Doctor Lives.
