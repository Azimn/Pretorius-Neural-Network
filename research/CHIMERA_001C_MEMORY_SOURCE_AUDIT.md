# Experiment 001C intake: 450-event autobiographical source and evaluation protection

**Date:** 2026-10-09  
**State:** Source audit, no behavioral labels and no neural model training.

Source is `Azimn/Pretorius-Connectome` commit `5364f43dfe3c192b6c13b7bf373405ee7a41b420`, specifically `memories/current/Pretorius_v12_450_Events_Complete.jsonl` and the aligned `memories/annotations/v12_450_sidecars.jsonl`. Do not duplicate source ownership, rewrite the original archive, or substitute earlier v7/v10/v11 snapshots. CI audits a pinned checkout and records both content SHA-256 digests.

An independent pre-execution schema survey found **450 unique events across 27 episodes**. The core fields `decisions`, `consequences`, `belief_changes`, and `relationship_changes` appear in all 450. Each has a unique cue/perception sidecar, but every sidecar still says **`unreviewed_candidate`**. Only 250 events contain `causal_inference_status`; 200 omit it. Missing is *unknown*, not proof of absent causal mechanisms.

A graph audit of `links_to_prior_events` found **912 directed event references** with no dangling targets. Treating links as undirected for split-integrity auditing yields only **two components**: one spanning **448 events across all 27 episodes**, and a second spanning the remaining two events. Therefore naive episode splits do not guarantee source-graph independence. A descriptive episode split of E01-18 / E19-22 / E23-27 contains 287 / 66 / 97 events and has 121 direct cross-role references; that split is **rejected as an independent evaluation design**. These numbers describe autobiographical links, not information leakage proven in a trained model. Natural interconnectedness may be appropriate for developmental cognition even when it makes conventional partitioning difficult.

`scripts/audit_chimera_001c_v12.py` records exact source file digests, completeness, annotation state, graph components and the proposed review queue. The output queue contains source pointers plus `decisions`, `consequences`, and `belief_changes` so an adjudicator can inspect them in context. It sets **`target_actions: null` on every row**, leaves `evaluation_role` unassigned, and refuses unexpected source motor labels. The queue does **not** manufacture target distributions from autobiographical prose. The 450-event archive is not an independent behavioral ground truth, and annotations remain candidate interpretations.

**Next gate:** develop new nonterminal counterfactual scenarios *after* freezing the autobiographical source. Require two independently recorded action-label judgments, disagreement tracking, and provenance for each ten-action target. Compare to a strong class-prior baseline and explicit episode/reference overlap diagnostics. The source corpus can enter the developmental experience track without learning explicit motor labels only after a budget-matched developmental protocol is frozen, with its own separate outcomes.
