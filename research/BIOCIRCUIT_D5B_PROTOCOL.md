# BC01-D5B preregistered development correction: cue-minus-blank eligibility

**Frozen before inspecting first D5B full-source results, 2026-10-08.** Directly motivated and specified in the earlier D5A [measured report](../results/biocircuit/BC01_D5_RESULTS.md) and [Issue #35](https://github.com/Azimn/Pretorius-Neural-Network/issues/35). This is an explicitly posthoc *engineering correction* of the D5A mechanistic bottleneck, not a statistical confirmatory test or an identity benchmark.

## One permitted change

D5A found the existing rule `max(cue_pre_rate - target_rate,0)` made 100% of action-incoming edges eligible at low sensory input and 97.1% at high input. Replace that **one presynaptic multiplier** with `max(cue_pre_rate - blank_pre_rate, 0)`. Compute `blank_pre_rate` by running the existing network for the same first-half ticks from the same reset initial fast state using zero sensory input. Save and exactly restore the cue branch `v`, `rate` and `tick` before the original no-teacher/teacher second-half comparison. Keep unchanged the originally gated postsynaptic target response, target action/population mask, learning rate 0.03, sparse CSR indices, Dale-like synaptic sign constraint, maximum weight, action readout and all source data.

The matched blank branch adds **16 untrained inference ticks per source card exposure** in addition to the original D4 cue/no-teacher/teacher steps. It is not compute-matched to D4, and costs must be recorded. The unmodified D4 code path remains the default; tests and paired runs ensure its results are exactly identical to the historical source-v2 baseline.

## Frozen data and testing conditions

- 450 reconstructed first-person v12 Pretorius memories, frozen Git blob `718dcc2d5ba4feccdef1690d447edfcebaa9bfb5`. The 16 interpreted decision/action labels derive only from source `decisions` fields; they are provisional development labels. No event ID, action or target enters evaluation stimulus.
- One source-owned deterministic L2 v2 TF-IDF cache per episode-disjoint seed, provider Git commit `7cd631f3b533203e39465ec31c4ee42945610e2f`; 256-dimensional BC01 L3 projection. Do not refit vocabulary.
- 256-neuron original `PlasticRecurrentPersonaNet`, seeds **31, 37, 43**, modes **local, global, generic** and source sensory gains **1× and 12×**; 18 matched conditions. 450-background-memory curriculum remains at gain 1 with eight ticks per event, three epochs × 16 source cards × 32 card ticks, 32 probe-settling ticks.
- Compare *unchanged* historical D4 targeted local eligibility with new cue-minus-blank target. Controls for the corrected network: recurrent W only lesion back to pre-card baseline, deterministic wrong-label shuffling, **blank sensory cues during teaching** (expected exactly zero recurrent update from corrected rule), no new card learning, original generic Hebbian and independently trained motor-decoder-only reference. Motor-only control trains supervised output weights and explicitly freezes W; neural recurrence cannot take credit for its success.
- For each condition preserve trained action accuracy and confusion/count histogram, per-card source-anchored scores, exact W checkpoint and restart, recurrent L1 changes, per-source and mean *eligible edge fraction*, actual updates, saturation/spread from existing readout, relative control performance and wall time. Cross-process independent seed and `PYTHONHASHSEED` replay must match all numeric results after excluding runtime measurements. All 18 full outputs are committed permanently to GitHub, not just temporary Actions artifacts.

## Interpretation

The hypothesis is that subtracting matched blank firing removes global recurrent excitability from source-specific eligibility and reduces W updates on irrelevant edges. A lower eligible-edge fraction is an **engineering diagnostic**, not alone proof of memory. To qualify as development-positive, the corrected recurrent network must predict >1 action, beat balanced 25% chance and outperform, *at the same seed/mode/gain*, recurrent-only learned W lesion, wrongly permuted labels, blank-cue learning, no new card learning and generic Hebbian exposure; a selected seed is insufficient. Report the motor-only decoder separately as an alternative mechanism capable of supervised source-action classification, not positive recurrent memory.

The already reused 16 source cards cannot establish independent novel paraphrase or semantic generalization; any apparent successful condition needs independently written/reviewed held-out cues and contradictions, multiple held-out seeds and a distinct production migration approval. If no condition passes causal controls, record a negative result and stop indiscriminate learning-rate/gain sweeps. The Doctor Lives and FlyWire remain distinct unaffected projects.
