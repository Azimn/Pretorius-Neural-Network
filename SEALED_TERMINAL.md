# Sealed Terminal Battery

The Pretorius Phenotype Battery includes a 20-item terminal evaluation reserved for use after the experimental architecture and evaluation protocol are frozen.

Because this repository is public, the terminal inputs and scoring key are intentionally not committed here.

Precommitted SHA-256 hashes from Phenotype Battery v1:

- terminal inputs: `1e5d6aac471c8c9939199c77cf629acc52b89a7e392325e64175dd921a0a06c7`
- terminal scoring key: `31faa69df33084fa335225390c415bafc6c1d66e09cc148d58b471711920ec00`

When the terminal set is eventually opened, the files used for evaluation should be verified against these hashes before scoring. This allows us to demonstrate that the terminal battery was fixed before v0.4 development without exposing its contents during model selection.
