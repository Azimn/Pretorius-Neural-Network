# Pretorius Host Release Milestones

## v0.1 End-to-end local vertical slice

Exit criteria: a persistent host can ingest an event, update durable autobiographical, relationship, and commitment state, perform a cheap deterministic cognition tick without an LLM, construct a renderer-neutral realization request, and optionally render through Ollama. Restarting the process preserves state. Contract tests pass without Ollama installed.

## v0.2 Continuity runtime

Add concern ledger, affect residue, prospective commitments, habits and action values, initiative triggers, and longitudinal synthetic-life tests. Acceptance includes restart continuity, delayed commitment recall, relationship-specific behavior, and mechanism-lesion non-equivalence.

## v0.3 Neural phenotype integration

Expose the validated recurrent Pretorius mechanism behind a PhenotypeProvider adapter. Migrate only evidence-supported mechanisms from numbered experiments. Renderer receives decisions and state projections, never responsibility for manufacturing Pretorius identity.

## v0.4 Unattended local host

Add an adopted scheduler and tool boundary, safe capabilities, event-triggered expensive inference, offline cognition budget, crash recovery, and deterministic provenance. Continuous operation must not require continuous LLM calls.

## v0.5 Renderer-swap acceptance

Run blinded continuity tests across at least two renderer and model configurations. Release blocks include helpful-assistant collapse, autobiographical contradiction, relationship amnesia, commitment loss, initiative failure, and character-recognition degradation after renderer swap.
